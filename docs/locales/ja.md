# Eugene Park / パク・ユジン (@znbobziz-ship-it)

> 低遅延ネットワークオーディオ、リアルタイムLinuxカーネル、決定論的DSP基盤を研究・開発するシステムエンジニアです。

ハードウェアクロックと物理ネットワーク境界の直上で動作するソフトウェアの設計と実装を行っています。ロックフリー並行処理、ゼロコピー（Zero-Copy）パケット直列化、そして1サンプルの欠落も許されないリアルタイムオーディオグラフエンジンの開発に注力しています。

## 🧭 背景と主な関心領域

- **専門分野**: 低遅延分散オーディオ、組込みDSPファームウェア、リアルタイムシステムプログラミング

## 🚀 主なオープンソースプロジェクト

```
+-----------------------------------------------------------------------------+
| プロジェクト名| 言語      | 概要                                            |
+-----------------------------------------------------------------------------+
| wave-mesh     | Rust      | ゼロコピー・マルチキャストネットワークオーディオバス|
| synth-core    | C++20     | SIMD最適化ポリフォニックモジュラーDSP音源コア   |
| jitter-guard  | Rust / C  | マイクロ秒単位のPTPv2クロックドリフト監視CLI    |
| dsp-bench     | Zig / C   | IIR/FIRフィルタ計算効率クロスプラットフォーム評価 |
+-----------------------------------------------------------------------------+
```

### 1. `wave-mesh`
- **アーキテクチャ**: 標準的なローカルギガビットイーサネット環境で、64チャンネル 24-bit/96kHz オーディオストリームを欠落なく転送する非同期ゼロコピーオーディオデーモン。
- **特徴**: リングバッファ共有メモリ転送、マイクロ秒補正ジッターバッファ、PipeWire/JACKネイティブブリッジ機能。
- **スタック**: Rust, Linux `AF_PACKET`, `epoll`, PipeWire SPA.

### 2. `synth-core`
- **アーキテクチャ**: プラグインホストや組込みモジュラー（Eurorack）向けのリアルタイムDSPライブラリ。
- **特徴**: 帯域制限オシレータ（BLIT/BLEP）、オーバーサンプリング無遅延フィードバック（ZDF）フィルタ、オーディオ描画スレッド内での動的ヒープ確保ゼロの保証。
- **スタック**: C++20, AVX2 / ARM NEON SIMD組み込み関数, CMake.

### 3. `jitter-guard`
- **アーキテクチャ**: IEEE 1588 PTP パケットとハードウェアタイムスタンプ（`SO_TIMESTAMPING`）を受信し、パケット遅延変動（PDV）を追跡するテレメトリツール。
- **特徴**: TUIベースのリアルタイム可視化、長期間解析用JSONLエクスポート、クロック同期逸脱アラート。
- **スタック**: Rust, `crossterm`, Linux Socket Timestamping API.

### 4. `dsp-bench`
- **アーキテクチャ**: 多様なCPUアーキテクチャ上で、1サンプルあたりの消費サイクル数（Cycles-per-sample）を測定・比較する軽量CLIツール。
- **特徴**: x86_64, aarch64, riscv64 をサポートし、ハードウェアカウンタと直接連携。
- **スタック**: Zig, C99, GNU Make.

## 📐 エンジニアリング設計思想

1. **決定論的実行の最優先**: リアルタイム音響処理において、遅れて届いたデータは破損データと同義です。動的メモリ確保、ミューテックスロック、ブロッキングシステムコールをオーディオ処理スレッドに持ち込むことはありません。
2. **暗黙的より明示的な設計**: 性能は後付けでは得られません。キャッシュ局所性を考慮したメモリ配置、構造体のパッキング、明確な所有権モデルがアーキテクチャの根幹をなします。
3. **推測せず計測せよ**: コンパイラの推測に頼らず、ハードウェアタイマー、サイクルカウンタ、eBPFトレースの実測値に基づいて最適化を進めます。
4. **耐障害性を生む簡素さ**: 過度に複雑なプロトコルは過酷な現場で脆さを見せます。削ぎ落とされたシンプルなパケット構造こそが、不安定な通信環境や突発的な電源断を生き残ります。
