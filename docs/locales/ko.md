# 박유진 / Eugene Park (@znbobziz-ship-it)

> 저지연 네트워크 오디오 스트리밍, 실시간 리눅스 커널, 결정론적 DSP 인프라를 연구하고 개발하는 시스템 엔지니어입니다.

하드웨어 클록과 물리 네트워크 인터페이스의 경계면에서 구동되는 소프트웨어를 설계하고 구현합니다. 락-프리(Lock-Free) 동시성 제어, 메모리 복사 없는(Zero-Copy) 패킷 직렬화, 단 1샘플의 손실도 허용하지 않는 실시간 오디오 그래프 엔진에 집중하고 있습니다.

---

## 🧭 배경 및 주요 관심사

- **전문 분야**: 저지연 분산 오디오, 임베디드 DSP 펌웨어, 실시간 시스템 프로그래밍
- **커널 및 운영체제**: Linux `PREEMPT_RT`, PipeWire / JACK 그래프 서브시스템, ALSA 드라이버 내부 구조
- **네트워크 및 동기화**: IEEE 1588 PTPv2 정밀 시각 동기 프로토콜, AES67, RTP/RTSP, 로우 소켓 멀티캐스팅
- **현재 탐구 영역**: RISC-V RVV 1.0 및 ARM NEON 벡터 가속 DSP 루틴, 락-프리/웨이트-프리 SPMC 큐 구조

## 🚀 주요 오픈소스 프로젝트

```
+-----------------------------------------------------------------------------+
| 프로젝트명    | 언어      | 설명                                            |
+-----------------------------------------------------------------------------+
| wave-mesh     | Rust      | 제로카피 멀티캐스트 네트워크 오디오 라우팅 버스 |
| synth-core    | C++20     | SIMD 기반 폴리포닉 모듈러 DSP 신디사이저 코어   |
| jitter-guard  | Rust / C  | 마이크로초 단위 PTPv2 클록 드리프트 모니터링 CLI|
| dsp-bench     | Zig / C   | IIR/FIR 필터 연산 효율 측정 크로스플랫폼 벤치마크|
+-----------------------------------------------------------------------------+
```

### 1. `wave-mesh`
- **구조**: 표준 로컬 기가비트 이더넷 환경에서 64채널 24-bit/96kHz 오디오 스트림을 손실 없이 전송하는 비동기 제로카피 오디오 데몬.
- **주요 특징**: 링 버퍼 기반 공유 메모리 전송, 마이크로초 단위 드리프트 보정 지터 버퍼, PipeWire/JACK 네이티브 브릿지 모듈 탑재.
- **기술 스택**: Rust, Linux `AF_PACKET`, `epoll`, PipeWire SPA.

### 2. `synth-core`
- **구조**: 오디오 플러그인 호스트 및 임베디드 유로랙(Eurorack) 모듈을 위한 실시간 모듈러 DSP 라이브러리.
- **주요 특징**: 대역 제한 발진기 생성(BLIT/BLEP), 오버샘플링 무지연 피드백(ZDF) 필터, 오디오 스레드 내 힙 메모리 동적 할당 0건 보장.
- **기술 스택**: C++20, AVX2 / ARM NEON SIMD 내장 함수, CMake.

### 3. `jitter-guard`
- **구조**: IEEE 1588 PTP 패킷과 하드웨어 타임스탬프(`SO_TIMESTAMPING`)를 패시브 모니터링하여 패킷 지연 편차(PDV)를 추적하는 텔레메트리 도구.
- **주요 특징**: TUI 기반 실시간 시각화, 장기 지터 로깅을 위한 JSONL 익스포트, 클록 동기화 이탈 시 조기 알림 트리거.
- **기술 스택**: Rust, `crossterm`, Linux Socket Timestamping API.

### 4. `dsp-bench`
- **구조**: 다양한 CPU 아키텍처 환경에서 샘플당 소요 사이클 수(Cycles-per-sample)를 측정하여 오디오 DSP 알고리즘 효율을 비교하는 경량 CLI.
- **주요 특징**: x86_64, aarch64, riscv64 타깃 지원, 사이클 단위 정밀 하드웨어 카운터 직결 연동.
- **기술 스택**: Zig, C99, GNU Make.

## 📐 엔지니어링 철학

1. **결정론적 실행 우선**: 실시간 오디오에서 늦게 도착한 데이터는 손상된 데이터와 같습니다. 메모리 동적 할당, 뮤텍스 락, 블로킹 시스템 콜은 절대 오디오 렌더 스레드에 진입시키지 않습니다.
2. **암시적인 것보다 명시적인 설계**: 성능은 사후 튜닝으로 얻어지지 않습니다. 캐시 친화적 메모리 배치, 구조체 패킹, 엄격한 데이터 소유권 분리가 시스템 구조를 결정합니다.
3. **추측하지 말고 측정하라**: 컴파일러의 자의적 최적화를 맹신하지 않고, 하드웨어 타이머, 사이클 카운터, eBPF 추적 결과를 바탕으로 리팩토링합니다.
4. **회복탄력성을 갖춘 단순함**: 복잡한 프로토콜은 예상치 못한 네트워크 지연이나 전원 이상에서 먼저 무너집니다. 간결하고 모듈화된 패킷 구조만이 불안정한 현장 환경을 견딥니다.
