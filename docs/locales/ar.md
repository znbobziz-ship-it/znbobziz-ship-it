# يوجين بارك / Eugene Park (@znbobziz-ship-it)

> مهندس نظم متخصص في معالجة الصوت الشبكي فائق الانخفاض في زمن الوصول، ونواة لينكس للزمن الحقيقي، والبنية التحتية الحتمية لمعالجة الإشارات الرقمية (DSP).

أقوم بتصميم وتطوير برمجيات تعمل بالقرب الشديد من الساعات العتادية والطبقات الفيزيائية لشبكات الاتصال. يرتكز عملي اليومي على التزامن البرمجي الحر بدون أقفال (*Lock-Free*)، والتحويل المتسلسل للحزم بدون نسخ زائد في الذاكرة (*Zero-Copy*)، ومحركات الرسوم البيانية الصوتية التي لا تقبل فقدان عينة صوتية واحدة على الإطلاق.

---

## 🧭 الخلفية والاهتمامات التقنية

- **مجال التخصص**: الصوت الموزع بزمن وصول منخفض، البرمجيات الثابتة للأنظمة المدمجة (DSP)، برمجة أنظمة الزمن الحقيقي الصارم (*Hard Real-Time*).
- **النواة ونظام التشغيل**: لينكس مع ترقيعة `PREEMPT_RT`، الأنظمة الفرعية PipeWire و JACK، البنية الداخلية لمشغلات ALSA.
- **الشبكات والمزامنة**: بروتوكول مزامنة التوقيت فائق الدقة IEEE 1588 PTPv2، ومعيار AES67، وبروتوكولات RTP/RTSP، والبث المتعدد عبر المقابس المباشرة (*Raw Sockets*).
- **مجالات البحث الحالية**: خوارزميات المعالجة الرقمية الشعاعية على معماريتي RISC-V RVV 1.0 و ARM NEON، وطوابير الحلقات الخالية من الانتظار (*Wait-Free SPMC*).

## 🚀 أبرز المشاريع مفتوحة المصدر

```
+-----------------------------------------------------------------------------+
| اسم المشروع   | اللغة     | الغرض والوظيفة                                  |
+-----------------------------------------------------------------------------+
| wave-mesh     | Rust      | ناقل صوتي شبكي بتقنية البث المتعدد بدون نسخ     |
| synth-core    | C++20     | محرك تركيبي معياري متعدد الأصوات مدعوم بـ SIMD  |
| jitter-guard  | Rust / C  | أداة سطر أوامر لمراقبة انحراف توقيت PTPv2 بدقة  |
| dsp-bench     | Zig / C   | معيار قياس كفاءة مرشحات IIR/FIR عبر المعماريات |
+-----------------------------------------------------------------------------+
```

### 1. `wave-mesh`
- **البنية المعمارية**: عفريت صوتي غير متزامن بدون نسخ للبيانات (*Zero-Copy*) ينقل 64 قناة صوتية بدقة 24 بت و 96 كيلوهرتز عبر شبكات الإيثرنت المحلية القياسية دون أي انقطاع.
- **أبرز المزايا**: النقل عبر الذاكرة المشتركة المعتمدة على المخازن الدائرية، والتعويض التلقائي عن اضطراب الحزم بالميكروثانية، وجسور ربط أصلية مع PipeWire و JACK.
- **المجموعة التقنية**: Rust, Linux `AF_PACKET`, `epoll`, PipeWire SPA.

### 2. `synth-core`
- **البنية المعمارية**: مكتبة معالجة إشارات رقمية معيارية للزمن الحقيقي مخصصة لمستضيفات الإضافات الصوتية ووحدات Eurorack العتادية.
- **أبرز المزايا**: مذبذبات محدودة النطاق الترددي (BLIT/BLEP)، مرشحات التغذية الراجعة بدون تأخير (ZDF)، وضمان عدم إجراء أي تخصيص ديناميكي للذاكرة أثناء مسار معالجة الصوت.
- **المجموعة التقنية**: C++20, تعليمات SIMD المضمنة AVX2 / ARM NEON, CMake.

### 3. `jitter-guard`
- **البنية المعمارية**: أداة قياس عن بُعد تستمع سلبيًا لحزم IEEE 1588 PTP والطوابع الزمنية العتادية لبطاقة الشبكة (`SO_TIMESTAMPING`) لحساب تباين تأخير الحزم (PDV).
- **أبرز المزايا**: واجهة طرفية تفاعلية (TUI)، تصدير منظم بتنسيق JSONL للتحليل الزمني الممتد، وتنبيهات مبكرة عند انحراف توافق الساعات.
- **المجموعة التقنية**: Rust, `crossterm`, Linux Socket Timestamping API.

### 4. `dsp-bench`
- **البنية المعمارية**: أداة سطر أوامر مدمجة لقياس عدد دورات المعالج المستهلكة لكل عينة صوتية عند تشغيل خوارزميات الفلترة الصوتية عبر معالجات متعددة.
- **أبرز المزايا**: دعم كامل لمعماريات x86_64 و aarch64 و riscv64 مع قراءة مباشرة لسجلات الأداء العتادية.
- **المجموعة التقنية**: Zig, C99, GNU Make.

## 📐 فلسفة الهندسة البرمجية

1. **حتمية التنفيذ أولاً**: في معالجة الصوت بالزمن الحقيقي، البيانات المتأخرة هي بيانات تالفة تماماً. يُحظر تماماً دخول التخصيص الديناميكي للذاكرة أو أقفال الاستبعاد المتبادل أو نداءات النظام المحظورة إلى خيط معالجة الصوت.
2. **التصميم الصريح يتفوق على الافتراضات الضمنية**: الأداء العالي لا يُضاف كإجراء تجميلي لاحق. توزيع الذاكرة المتوافق مع الكاش، وتراصف الهياكل البيانية، وتحديد ملكية البيانات بوضوح يحدد الشكل المعماري للبرمجيات.
3. **القياس الدقيق بدلاً من التخمين**: لا نعتمد مطلقاً على حدس المترجم، بل تُبنى قرارات إعادة الهيكلة والتطوير حصرياً على بيانات الموقتات العتادية، وعدادات الدورات، وتتبع eBPF.
4. **البساطة تصنع المتانة**: البروتوكولات المعقدة تتداعى سريعاً تحت ظروف الشبكات الواقعية أو انقطاع التغذية. البنية البسيطة الخالية من التعقيد الزائد هي وحدها القادرة على الصمود في بيئات العمل القاسية.
